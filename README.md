# TIDEBREAKER JACKPOT (demo build)

This is a free-to-play browser demo build of TIDEBREAKER JACKPOT, an original underwater shooting game.
It uses play credits only. There is no real money, no purchases and no prizes.

Play: https://mikerasmussen1.github.io/tidebreaker-jackpot-demo/

This repository holds only the compiled web build, not the source.
